# OpenCode

## What It Is

OpenCode is a free, open-source AI coding agent that runs in your terminal, desktop, or IDE. It supports 75+ language models and is built for developers who want a privacy-first, vendor-agnostic coding assistant without lock-in.

## What It's Used For

- AI-powered terminal-based code generation and assistance
- Code analysis, refactoring, and multi-file editing
- Multi-step coding tasks with persistent session management
- Developer experimentation and model switching across providers
- Privacy-sensitive development where code stays on your machine

## Key Features

- **75+ Model Support** — Claude, GPT, DeepSeek, Gemini, Groq, Azure OpenAI, Ollama, OpenRouter, and more
- **Zero Data Storage** — No code or context data stored externally
- **Dual Agent Modes** — "Build" agent (full access) and "Plan" agent (read-only analysis)
- **Session Management** — Persistent conversation context across sessions
- **Built-in Editor** — Vim-like editor with LSP support
- **Desktop App** — Available as a standalone desktop application
- **MIT Licensed** — Fully open source

## How to Get Started

**Quick install:**

```bash
curl -fsSL https://opencode.ai/install | bash
```

**Other options:** Homebrew, npm, Scoop, or download the desktop app from [opencode.ai/download](https://opencode.ai/download)

**Run:**

```bash
opencode
```

Works immediately with your existing API keys from any supported provider.
