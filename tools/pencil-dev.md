# Pencil.dev

## What It Is

Pencil.dev is an AI-powered design canvas that integrates directly into your IDE (Cursor, VS Code, Claude Code) as an extension. It brings pixel-perfect vector-based UI design into your code editor, enabling seamless design-to-code workflows without leaving your development environment.

## What It's Used For

- Designing and prototyping UIs directly within your IDE
- Generating production-ready code from visual designs using AI
- Creating component-based design systems version-controlled in Git
- Bridging the design-to-code handoff by keeping designs and code in sync
- Converting Figma designs into code-based design systems
- Iterating on UI designs with AI-assisted refinement

## Key Features

- **Infinite Canvas** — Unrestricted UI design within your editor
- **Git-Native** — JSON-based `.pen` format stored in your repo, branch and merge like code
- **AI-Driven** — Design generation and refinement powered by Claude models
- **Figma Import** — Copy-paste frames and assets while preserving vectors and styles
- **Auto Code Generation** — Converts visual designs into clean HTML, CSS, and React components
- **MCP Integration** — Model Context Protocol support for enhanced AI capabilities
- **IDE Extension** — Available for VS Code, Cursor, and Claude Code
- **Standalone App** — Desktop application for macOS and Linux

## How to Get Started

**IDE Extension:**

Install from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=highagency.pencildev) or directly in Cursor.

**Standalone Desktop:**

Download from [pencil.dev/downloads](https://www.pencil.dev/downloads) for macOS and Linux.

**Requirements:** Claude Code subscription or compatible IDE with MCP support for full AI functionality.
