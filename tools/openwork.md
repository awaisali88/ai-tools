# OpenWork

## What It Is

OpenWork is an open-source desktop application for running AI agents, skills, and MCP servers locally. It provides a guided interface for workflow automation with a local-first architecture and optional cloud connectivity.

## What It's Used For

- Local-first AI agent workflow automation
- Running AI coding agents on your desktop without remote infrastructure
- Automating repetitive knowledge work tasks
- Building and managing reusable AI workflow skills
- Desktop-based computer use automation with permission controls

## Key Features

- **Local-First** — Runs AI servers on your machine in the background
- **Multiple Interfaces** — Desktop app, CLI tool (Openwrk), and WhatsApp bot
- **Session Management** — Create and manage agent workflows easily
- **Real-Time Updates** — Server-sent events for live progress monitoring
- **Permission Controls** — Granular access controls for agent actions
- **Execution Timeline** — Detailed history of agent actions and results
- **Skills Manager** — Install, organize, and manage agent extensions
- **Template Saving** — Save repeatable processes for reuse
- **MIT Licensed** — Fully open source

## How to Get Started

**Option 1 — Desktop app (recommended):**

Download from [GitHub releases](https://github.com/different-ai/openwork/releases)

**Option 2 — CLI:**

```bash
npm install -g openwrk
```

**Option 3 — Build from source:**

```bash
git clone https://github.com/different-ai/openwork.git
cd openwork
pnpm install
pnpm dev
```

Requires Node.js, pnpm, and Rust toolchain for building from source.
