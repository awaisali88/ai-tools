# Recall AI

## What It Is

Recall AI is a personal knowledge management system that consolidates bookmarks, notes, and reading lists into a unified, searchable knowledge base powered by AI. It acts as a "second brain" that organizes, summarizes, and retrieves information across multiple content types.

## What It's Used For

- Building a personal knowledge base from diverse content sources
- AI-powered summarization of articles, videos, podcasts, and documents
- Organizing and retrieving saved research materials
- Learning faster through spaced repetition and active recall
- Knowledge synthesis through AI-powered tagging and connections

## Key Features

- **AI Summaries** — Instant summaries for quick content preview (skip 3-hour videos for 30-second overviews)
- **Multi-Content Support** — Articles, YouTube videos, podcasts, PDFs, Google Docs, Google Slides, and TikToks
- **Smart Tagging** — Automatic categorization that learns and improves over time
- **Knowledge Graph** — Automated connection-finding across related ideas and insights
- **Universal Chat** — Query across all saved content for contextual results
- **Spaced Repetition** — Built-in learning technique for optimal retention
- **Cross-Platform** — Desktop apps (Mac/PC), Chrome and Firefox extensions
- **Privacy-First** — Data is never used for AI model training

## How to Get Started

1. Visit [getrecall.ai](https://www.getrecall.ai/) to create an account
2. Install the browser extension for [Chrome](https://chrome.google.com/webstore) or Firefox
3. Download the desktop app for Mac or Windows
4. Save content with one click from anywhere online
